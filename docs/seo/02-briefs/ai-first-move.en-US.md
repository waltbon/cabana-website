## Estructura fija
1. **Client moment:** an idea is chosen, conviction exists, but no approval for a big project, and a document won't get it.
2. **Promise:** a working AI use case in production + an investment case you can defend before the board.
3. **What you get:** one use case in production your team can operate; documented, approved case definition; investment case (target architecture, effort, sequence, estimated return on real evidence); prep session before presenting internally.
4. **How it works:** Cycle 1 build (weeks 1–7; week 1 confirms viability; built with your technical team inside); Cycle 2 investment case (weeks 8–10). "AI proposes, your team decides."
5. **Duration and price:** 10 weeks, two cycles; USD 24,500 fixed (impuesto C5); 30/40/30.
6. **Who it's not for:** no chosen idea → Ruta IA; decision+budget+mandate → direct project; data not accessible → data project first; large or multiple use cases → custom quote.
7. **FAQ:** "Expensive for one use case?" → you're buying approval for the program · "How many of our people?" → one technical person, a few hours/week · "Can we add a second use case?" → separate program · "Is this a proof of concept?" → no; it stays in production (ver P5).
8. **CTA:** Book a conversation. Puente desde Ruta IA: "[Ruta IA] told you where to start. AI First Move is starting."
